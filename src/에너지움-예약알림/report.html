코미포에너지움 견학 예약 안내 알림 도입 제안

제안: 중부발전서비스 코미포에너지움 운영 담당 → 한국중부발전 기획홍보부 · 2026. 10.
홈페이지 견학 신청 기능에 예약 확정·방문 전날 안내를 신청자에게 카카오 알림톡으로 보내는 기능을 추가할 것을 제안합니다. 새 시스템이 아니라 기존 기능에 발송만 연결하는 작업이며, 발송비는 연 5천 원 안팎입니다.
월 15건홈페이지 예약(전화 예약 별도)
0건현재 예약자에게 가는 안내
연 5천 원 안팎예상 발송비

현재 문제

구분현재영향
예약 확인접수·승인 여부를 신청자가 알 수 없음확인 문의 전화 다수
방문 안내주차·오시는 길 사전 안내 없음주차 등 문의 반복
방문 전 알림전날 안내 없음노쇼(예약 후 미방문) 잦음
전화 예약전화 접수 후 '임시휴무'로 시간만 막아 중복 방지예약자 정보가 시스템에 남지 않아 안내 불가
이미 있는 기능 · 관리 화면 견학 신청 상세에 신청자 연락처, 예약일·시간, '승인여부' 선택, '사용자전달메세지' 입력란이 있으나 신청자에게 발송되지 않음.

제안하는 알림 흐름

① 승인 저장 시② 방문 전날
일시·인원·도슨트 여부, 주차·오시는 길, 사용자전달메세지일정 재안내, 변경·취소 연락처
※ 카카오톡 미사용 등으로 발송에 실패한 건은 대행사 화면에 표시되며 담당자가 전화로 안내.
접수 알림 없음 · 신청 직후 접수 알림은 보내지 않음 → 홈페이지 신청 완료 화면에 '담당자 확인 후 1~2영업일 안에 카카오톡으로 확정 안내를 드립니다' 문구 표시. 바로 이어지는 확정 알림과 겹치지 않고, 수작업 발송 시에도 부담이 없음.
전화 예약 처리 · 관리 화면에 '관리자 직접 등록' 기능 추가 → 실제 예약으로 등록하면 그 시간이 자동 마감되어 중복 방지 유지 + 홈페이지 예약과 똑같이 알림 발송 + 예약 정보 일원화. 전화 접수 시 연락처 수집·이용을 구두로 안내하고 동의받음.

추진 방안

안A · 기존 발송 시스템 연결

본사가 이미 쓰는 알림톡 발송 계약에 견학 신청 기능 연결

장점새 계약·채널 불필요, 가장 빠름

확인본사 발송 시스템 유무

안B · 알림톡 신규 도입

카카오톡 채널 개설 후 공식 발송 대행사와 계약, 홈페이지 연동

장점발송비 저렴, 카카오톡으로 확인 쉬움

확인채널 명의, 연동 개발

병행

안C · 알림톡 수작업 발송

채널 개설·문구 심사까지만 준비하고, 연동 개발 전에는 대행사 웹 화면에서 담당자가 확정·전날 알림톡을 직접 발송(전날 안내는 예약 발송 기능 이용)

장점개발 없이 시작, 전화 예약에도 적용

한계채널·대행사 준비 필요, 수작업

본사 발송 시스템이 있으면 안A, 없으면 안B. 어느 쪽이든 개선 전까지 안C를 병행하고, 문의·노쇼 감소 효과를 수치로 기록해 근거 자료로 활용.
